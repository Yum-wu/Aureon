# Aureon 功能详解 - 常见问题

## RAG 检索是如何工作的？

Aureon 采用多阶段 RAG 流水线：

1. **查询分类**：判断查询复杂度（简单/中等/复杂）
2. **查询重写**：生成多个查询变体，扩展召回
3. **混合检索**：BM25 关键词检索 + Dense 向量检索 + RRF 融合
4. **重排序**：自适应重排序，基于置信度阈值过滤
5. **上下文压缩**：当上下文过长时自动压缩
6. **答案生成**：LLM 基于检索结果生成答案
7. **引用注入**：自动添加来源引用标记

**简单查询**：纯关键词检索（<10ms）
**中等查询**：混合检索 + 自适应重排序
**复杂查询**：HyDE + 多查询 + 集成重排序 + CRAG

## 什么是 HyDE？

HyDE（Hypothetical Document Embeddings）是一种检索增强技术：

1. LLM 先生成一个"假设答案"
2. 将假设答案向量化
3. 用假设答案的向量去检索相似文档

**效果**：提升复杂查询的检索准确率，因为假设答案比原始查询更接近真实文档。

## 什么是 CRAG？

CRAG（Corrective RAG）是一种检索质量评估机制：

1. 检索完成后，评估检索结果的质量
2. 根据置信度分三档处理：
   - **高置信度**：直接使用检索结果生成答案
   - **中置信度**：重写查询，重新检索
   - **低置信度**：返回"未找到相关结果"

**效果**：避免基于低质量检索结果生成错误答案。

## 语义缓存如何工作？

语义缓存通过余弦相似度去重：

1. 用户查询时，先计算查询向量
2. 在缓存中查找相似度 > 0.92 的历史查询
3. 如果命中，直接返回缓存答案（<10ms）
4. 如果未命中，执行完整 RAG 流程并缓存结果

**效果**：78% 缓存命中率，显著降低延迟和成本。

## 多级记忆系统是什么？

Aureon 实现了四层记忆系统：

| 层级 | 存储 | 职责 |
|------|------|------|
| L0 | SQLite | 原始对话记录 |
| L1 | SQLite | 原子事实三元组 |
| L2 | Markdown 文件 | 场景总结 |
| L3 | Markdown 文件 | 用户画像（≤2KB） |

**会话管理**：
- 30 分钟无活动自动结束会话
- 最多保留 20 轮对话
- 上下文超过 1000 字符时自动卸载

## 支持哪些文档格式？

| 格式 | 支持状态 | 说明 |
|------|----------|------|
| .md | ✅ 完全支持 | Markdown 格式，推荐使用 |
| .txt | ✅ 完全支持 | 纯文本格式 |
| .pdf | ✅ 支持 | 自动提取文本 |
| .docx | ✅ 支持 | Word 文档 |
| .xlsx | ✅ 支持 | Excel 表格 |

**大小限制**：10MB
**分块策略**：语义分块（可配置块大小和重叠）

## 什么是自适应重排序？

自适应重排序根据查询复杂度动态调整：

```python
_RERANK_THRESHOLDS = {
    "simple": 0.55,   # 简单查询：较高阈值
    "medium": 0.40,   # 中等查询：中等阈值
    "complex": 0.30   # 复杂查询：较低阈值
}
```

**效果**：简单查询更严格过滤，复杂查询保留更多候选。

## 工具调用有哪些？

Aureon Agent 支持以下工具：

1. **calculator**：数学计算
2. **read_ref**：读取参考文档
3. **knowledge_retrieval**：搜索知识库
4. **web_search**：Tavily 网络搜索（需配置 API Key）

## 如何使用内容工作室？

内容工作室（Crew）可以 AI 生成文章：

1. 访问 `/crew` 页面
2. 输入文章主题
3. 点击"生成文章"
4. AI 自动生成结构化文章

**用途**：快速生成知识库文档、博客文章、技术文档。

## 仪表盘显示哪些指标？

实时仪表盘显示：

- **Golden Signals**：延迟、流量、错误、饱和度
- **系统健康**：API 服务器、数据库、缓存、Qdrant、Redis、LLM API、Embedding
- **查询分析**：查询分布、响应时间、Token 使用
- **缓存性能**：命中率、趋势图
- **RAG 流水线**：检索时间、生成时间、总延迟

## 如何查看审计日志？

1. 访问 `/admin` 页面
2. 切换到"审计日志"标签
3. 可按时间、用户、操作类型筛选
4. 支持导出为 CSV/JSON

**记录的操作**：登录、查询、上传、配置变更等。
