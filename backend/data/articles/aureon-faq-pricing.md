# Aureon 定价与成本 - 常见问题

## Aureon 如何定价？

Aureon 是**自托管**的企业级平台，采用以下模式：

- **软件本身**：开源/企业许可（具体取决于版本）
- **运行成本**：用户自行承担 LLM API 调用费用
- **基础设施**：用户自行承担服务器/云服务费用

**不是 SaaS 按席位收费模式**，用户完全掌控自己的部署和数据。

## 使用 Aureon 的成本是多少？

### LLM API 成本

| 模型 | 单次查询成本 | 说明 |
|------|-------------|------|
| Qwen 3.5 Flash | ~$0.001 | 默认模型，性价比最高 |
| GPT-4o | ~$0.01 | OpenAI 模型 |
| Claude | ~$0.008 | Anthropic 模型 |

**月度成本估算**（基于 Qwen）：
- 100 次/天 × 30 天 = 3000 次/月 → ~$3
- 1000 次/天 × 30 天 = 30000 次/月 → ~$30
- 10000 次/天 × 30 天 = 300000 次/月 → ~$300

### 基础设施成本

| 组件 | Railway | 自托管 |
|------|---------|--------|
| 应用服务器 | $5-20/月 | 按云服务商计费 |
| Qdrant Cloud | $25-100/月 | 自托管免费 |
| Redis | $5-15/月 | 自托管免费 |
| 域名/SSL | 按注册商 | 按注册商 |

**总计**：约 $35-135/月（Railway）或 $10-50/月（自托管）

## 如何控制成本？

### 1. 启用语义缓存

语义缓存可避免重复查询调用 LLM：
- 缓存命中率：78%
- 缓存查询成本：$0（仅向量计算）

### 2. 使用成本治理模块

Aureon 内置成本治理功能：

- **预算管理**：设置月度/季度预算上限
- **成本追踪**：按用户、工作空间细分
- **预警机制**：接近预算时自动告警
- **趋势分析**：预测未来支出

访问 `/admin` → "成本治理" 标签查看。

### 3. 优化查询策略

- 简单查询使用纯向量检索（更快更便宜）
- 启用查询路由，避免复杂查询过度处理
- 批量处理非实时查询

### 4. 选择合适的模型

| 场景 | 推荐模型 | 原因 |
|------|---------|------|
| 日常查询 | Qwen 3.5 Flash | 性价比最高 |
| 复杂推理 | GPT-4o | 质量最好 |
| 多语言 | Claude | 多语言能力强 |

## 如何查看 Token 使用量？

### 实时查看

1. 访问 `/dashboard` 页面
2. 查看"Token 使用"图表
3. 支持按日/周/月筛选

### API 查询

```bash
curl https://your-domain/api/analytics/tokens?time_range=7d
```

### 导出报告

```bash
curl https://your-domain/api/cost/export?format=csv
```

## 如何设置预算告警？

1. 访问 `/admin` → "成本治理"
2. 点击"设置预算"
3. 输入月度预算金额
4. 配置告警阈值（如 80%）
5. 保存配置

当支出达到阈值时，系统会：
- 在仪表盘显示告警
- 发送邮件通知（如配置）
- 记录审计日志

## 成本优化最佳实践

1. **优先使用缓存**：重复查询不消耗 Token
2. **合理设置上下文窗口**：过长的上下文增加成本
3. **批量索引文档**：减少索引 API 调用
4. **监控异常查询**：防止恶意或无效查询浪费资源
5. **定期清理无用文档**：减少向量存储成本
