# PLG vs SLG：产品驱动增长的选择

## 两种增长模式

### PLG（Product-Led Growth）

产品驱动增长，让产品自身成为获客和转化的核心引擎：

- **核心理念**：产品即营销，用户体验驱动增长
- **关键指标**：产品激活率、免费转付费率、病毒系数
- **代表企业**：Slack、Notion、Figma、Zoom

### SLG（Sales-Led Growth）

销售驱动增长，通过销售团队推动获客和成交：

- **核心理念**：销售推动，关系和信任驱动增长
- **关键指标**：销售周期、客单价、赢单率
- **代表企业**：Salesforce、SAP、Oracle

## 对比分析

| 维度 | PLG | SLG |
|------|-----|-----|
| 获客方式 | 产品自传播 | 销售主动触达 |
| 试用门槛 | 低（免费试用） | 高（Demo+POC） |
| 销售周期 | 短（天-周） | 长（月-季度） |
| 客单价 | 低-中 | 中-高 |
| CAC | 低 | 高 |
| 扩展方式 | 自助升级 | 销售增购 |
| 适用客户 | SMB+个人 | 中大企业 |
| 团队构成 | 产品+增长 | 销售+SDR |

## 选择决策

```
客单价是多少？
├── <¥1000/月 → PLG
├── ¥1000-10000/月 → PLG+SLG 混合
└── >¥10000/月 → SLG

产品复杂度？
├── 自助上手 → PLG
├── 需要引导 → PLG+SLG
└── 需要定制 → SLG

决策链长度？
├── 单人决策 → PLG
├── 2-3 人 → PLG+SLG
└── 多部门 → SLG
```

## PLG 实施要点

1. **低门槛试用**：免费版或试用期，降低首次使用障碍
2. **快速到 Aha Moment**：新用户在 5 分钟内体验核心价值
3. **内置分享机制**：邀请队友、分享链接等病毒传播
4. **自助升级路径**：用量提示、功能锁定引导付费
5. **数据驱动优化**：追踪激活漏斗、转化路径

## 关键事实

1. **PLG 以产品为核心增长引擎**，CAC 低、销售周期短，适合低客单价、自助上手的产品
2. **SLG 以销售为核心增长引擎**，客单价高、销售周期长，适合复杂企业级产品
3. **PLG+SLG 混合模式**是越来越多 SaaS 企业的选择——PLG 获客，SLG 增购
4. **PLG 的关键是快速到 Aha Moment**，新用户应在 5 分钟内体验核心价值
5. **选择增长模式应基于客单价、产品复杂度和决策链长度**，不是所有产品都适合 PLG
