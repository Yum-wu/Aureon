# 数据驱动决策：指标体系与仪表盘设计

## 指标体系设计

### 北极星指标

北极星指标（North Star Metric）是公司最核心的一个指标，反映产品传递的核心价值：

```
北极星指标选择标准：
1. 反映客户核心价值
2. 代表产品策略方向
3. 是收入的先行指标
4. 易于理解和沟通

示例：
- Airbnb：预订夜晚数
- Slack：团队发送消息数
- Spotify：用户收听时长
- RAG 平台：成功查询数
```

### 指标层级

```
北极星指标
├── 输入指标（驱动北极星的指标）
│   ├── 新用户激活率
│   ├── 功能使用深度
│   └── 用户留存率
├── 过程指标（监控执行过程）
│   ├── 功能发布频率
│   ├── 客户支持响应时间
│   └── 系统可用性
└── 输出指标（北极星的结果）
    ├── 月度经常性收入（MRR）
    ├── 净推荐值（NPS）
    └── 客户生命周期价值（LTV）
```

## 仪表盘设计

### 设计原则

1. **分层展示**：高管看汇总，团队看细节
2. **对比展示**：与上周/上月对比，显示趋势
3. **异常高亮**：异常值用颜色标记
4. **行动导向**：每个指标旁边标注负责人

## 数据驱动决策流程

```
1. 定义问题：我们要回答什么问题？
2. 选择指标：哪些指标能回答这个问题？
3. 收集数据：从哪些系统获取数据？
4. 分析洞察：数据告诉我们什么？
5. 制定行动：基于洞察做什么？
6. 验证效果：行动是否改善了指标？
```

## 常见陷阱

1. **虚荣指标**：关注总注册数而非活跃用户数
2. **指标过多**：仪表盘指标超过 10 个，失去焦点
3. **缺乏行动**：看数据但不采取行动
4. **因果混淆**：相关性不等于因果性
5. **幸存者偏差**：只分析活跃用户，忽略流失用户

## 关键事实

1. **北极星指标是公司最核心的一个指标**，反映产品传递的核心价值，应是收入的先行指标
2. **指标分为三层**：输入指标（驱动北极星）、过程指标（监控执行）、输出指标（北极星的结果）
3. **仪表盘设计四原则**：分层展示、对比展示、异常高亮、行动导向
4. **虚荣指标是最常见的陷阱**——总注册数是虚荣指标，活跃用户数才是价值指标
5. **数据驱动决策六步流程**：定义问题 → 选择指标 → 收集数据 → 分析洞察 → 制定行动 → 验证效果
