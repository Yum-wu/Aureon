- **技术栈与构建**：采用 React 18 + TypeScript + Vite 架构，使用 Tailwind CSS v4 进行样式管理，通过 `react-router-dom` 实现客户端路由。
- **分层结构**：遵循标准的 UI 分层模式，`pages/` 负责路由级页面组合，`components/` 封装业务模块（如 `RagQuery`, `CrewGenerator`）与基础 UI 原子组件，`hooks/` 抽离复杂状态逻辑（如 `useChat` 处理 SSE 流式响应），`services/` 统一封装 API 请求与本地存储交互。
- **性能优化**：在 `App.tsx` 中实施路由级代码分割（Lazy Loading），配合 `Suspense` 提升首屏加载速度；在 `api.ts` 和 `useChat.ts` 中实现了带背压控制（Backpressure）的 SSE 流式解析机制，防止高频事件导致 UI 卡顿。
- **国际化与主题**：通过 `i18next` 实现中英双语切换，利用 CSS Variables (`design-tokens.css`) 和 Tailwind 插件支持深色/浅色主题及玻璃拟态视觉效果。
