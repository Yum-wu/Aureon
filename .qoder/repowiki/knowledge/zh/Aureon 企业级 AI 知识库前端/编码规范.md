- 自定义 Hook 封装复杂逻辑：将聊天状态、SSE 流处理及本地持久化逻辑封装在 `useChat` 等 Hook 中，实现视图与逻辑解耦。
- SSE 流式渲染优化：在 `api.ts` 和 `useChat.ts` 中采用文本缓冲（Text Buffering）与定时刷新（Flush Interval）策略，减少 React 重渲染次数。
- 设计令牌驱动样式：全局使用 CSS 变量（如 `--bg-primary`, `--accent`）定义颜色与间距，并在组件中通过 `var(--...)` 引用以支持主题切换。
- 路由懒加载模式：所有页面组件均通过 `lazy(() => import(...))` 方式引入，确保按需加载代码块。
