- **入口与路由**：`app/main.py` 作为应用入口，通过 `include_router` 聚合功能模块（如 `chat`, `rag`, `crew`, `langgraph`），并配置 CORS、Prometheus 监控及结构化日志中间件。
- **核心工作流**：采用 LangGraph (`app/langgraph`) 实现状态机驱动的意图路由（Intent -> RAG/Agent/Chat -> Generate），支持并行节点执行；同时集成 CrewAI (`app/crew`) 处理复杂的多智能体文章生成任务。
- **数据与记忆层**：`app/memory` 实现 L0-L3 四级记忆模型（对话、原子事实、场景、人格），由 `MemoryManager` 统一管理生命周期；`app/rag` 封装 ChromaDB/Qdrant 向量存储及 BM25 关键词索引，支持多提供商 Embedding 降级策略。
- **基础设施**：`app/config` 基于 Pydantic Settings 管理环境变量；`app/cache` 提供 Redis 客户端用于语义缓存；`app/tools` 定义计算器、搜索等 MCP 兼容工具供 Agent 调用。
