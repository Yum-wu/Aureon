## 一、AI Coding 方向

### 1. 智谱 GLM-5.2 引爆硅谷，国产开源模型首次跻身「Coding 御三家」

- **时间**：2026-06-17 上线，06-22 港股市场强烈反应
- **来源**：凤凰网/商业内幕、财联社、新浪财经
- **事件**：智谱于 6 月 17 日上线并全量开源 GLM-5.2，专为长代码任务和智能体工作流设计。支持 **100 万 token 上下文窗口**，在 Code Arena 全球盲测中位列可用模型第一。Vercel CEO Guillermo Rauch 在 X 上发文「这将改变格局」，前 Meta/DeepMind 高管 Matt Velloso 称其为「第一款能当日常主力用的开源模型」。马斯克在 X 上预测中国模型达到 Anthropic Fable 水平「可能在 2027 年 Q1」，智谱创始人唐杰回应「不需要那么久」。受此推动，智谱港股 06-22 盘中最高涨逾 42%，市值首次突破 **1 万亿港元**。
- **值得关注的原因**：
  - 这是国产开源模型首次在全球 AI Coding 榜单上真正威胁闭源巨头，形成 Anthropic / OpenAI / 智谱「Coding 御三家」格局
  - GLM-5.2 发布正值 Anthropic Fable 5/Mythos 5 被美国出口管制、全球访问受限，国产模型承接「信任迁移」窗口期
  - Day-0 适配华为昇腾等 8 个国产算力平台，国产大模型 + 国产算力协同闭环正在成型
  - 对开发者：GLM-5.2 的 MIT 开源协议意味着可本地部署、可修改、可商用，是 Claude Code 的高性价比替代选项

### 2. OpenCode 登顶全球 AI 开发工具实力榜，开源 Agent 正式反超闭源

- **时间**：2026-06-16 LogRocket 发布榜单
- **来源**：威易网、LogRocket AI Dev Tool Power Rankings
- **事件**：开源终端 AI 编程智能体 **OpenCode** 在 LogRocket 2026 年 6 月版《AI 开发工具实力榜》中超越 Cursor、Claude Code 等所有闭源对手，登顶第一名。OpenCode 核心差异化：① **模型无关（Model-Agnostic）**，支持 75+ 个模型自由切换；② MIT 开源，可自托管；③ CLI 原生，契合资深开发者工作流；④ 社区飞轮，GitHub Stars 160K+，月活用户 750 万。
- **值得关注的原因**：
  - 标志 AI Coding 工具竞争主轴从「模型能力」转向「开放度 + 成本 + 不被厂商锁定」
  - OpenCode 基于终端的工作流正在复兴，对 Aureon 这类开发者工具产品的交互设计有参考意义
  - 小米 MiMo Code 正是基于 OpenCode 构建，说明头部厂商已开始用开源 Agent 底座 + 自研模型打造差异化产品

### 3. Anthropic 向美国国会提交 AI 安全监管建议，强制标准化监管时代开启

- **时间**：2026 年 6 月中旬（Anthropic 官方提交）
- **来源**：搜狐/36Kr AI 行业观察报告
- **事件**：Anthropic 正式向美国国会提交政策建议，提出「仅依靠企业自愿安全披露已无法适配前沿大模型风险管控需求」，建议建立 **第三方独立安全评估机制**，推动联邦层面统一 AI 监管框架。此举恰逢美国统筹各州 AI 法规的政策窗口期，预示全球 AI 行业从「自愿合规」迈入「强制安全测试 + 标准化风险评估」阶段。
- **值得关注的原因**：
  - Anthropic 作为前沿模型厂商主动推动强制监管，反映行业对「安全失控」风险的真实担忧
  - 若美国联邦层面落地强制安全评估，将直接影响所有出海 AI Coding 产品的合规成本
  - 对国内产品的启示：安全对齐、事实核验、风险提示能力将成为下一阶段国内外监管的共性底线

## 二、具身智能方向

### 4. 华为云 CloudRobo 全球首个全流程具身智能开发平台公测在即，产业化关键瓶颈破局

- **时间**：2026-06-05 发布，06-30 正式开启公测
- **来源**：腾讯新闻、华为云 INSPIRE 2026 创想者大会
- **事件**：华为云在 INSPIRE 2026 创想者大会上发布「行业 AI 梦工厂 · 具身智能专区」，同步推出全球首个端到端具身智能开发平台 **CloudRobo**，将于 6 月 30 日开启公测。平台打通「数据喂养 → 模型训练 → 云端部署 → 系统集成」全流程，依托 PB 级安全可信数据底座，实现三大突破：① 数据与模型双重评估体系过滤脏数据；② 模块化动力控模型支持积木式拼装，降低开发门槛；③ 机器人云端接入缩短至小时级，模型部署压缩至分钟级。国家地方共建人形机器人创新中心、亿嘉和、上海交大等已完成平台验证。
- **值得关注的原因**：
  - 具身智能从「单点技术突破」进入「平台化基础设施」阶段，华为云此举类似 AI Coding 领域的 GitHub Copilot 平台化
  - 云端分钟级部署能力将大幅降低中小团队进入具身智能赛道的门槛，可能引发一轮应用层创新
  - 对 Aureon：RAG + 具身智能的结合点（机器人知识库、操作手册检索）值得关注

### 5. 宇树科技 73 天闪电过会 + 联想入股，人形机器人「A 股第一股」即将诞生

- **时间**：2026-06-01 过会，06-03 联想入股官宣
- **来源**：新浪财经具身智能周报、凤凰网
- **事件**：宇树科技 IPO 申请从受理到过会仅 **73 天**，创科创板 2026 年最快审核纪录，拟募资 42.02 亿元，其中约一半投向「智能机器人模型研发」（远超本体研发的 11.1 亿元）。过会同日，英伟达 CEO 黄仁勋宣布与宇树联合推出新一代人形机器人参考设计 **H2+**，宇树负责本体、英伟达提供算力与软件栈，产品将于下半年上市。随后联想正式宣布入股宇树并签署战略合作协议，形成「英伟达 + 联想 + 宇树」的产业资本三角绑定。优必选消费级人形机器人同期开启预售，6 天订单突破 2110 台，验证 C 端市场初步可行性。
- **值得关注的原因**：
  - 宇树募资投向的变化（一半投模型研发 vs 11.1 亿投本体）印证行业竞争焦点已从「硬件本体」转向「具身智能大脑」
  - 英伟达 + 联想先后战略绑定宇树，说明产业资本正在围绕头部本体厂商构建生态闭环
  - 消费级人形机器人 3000 台预售订单，是「人形机器人走出工厂」的重要信号，具身智能的 ToC 应用场景探索正式开启
